# [Invidious](https://github.com/iv-org/invidious)

Invidious is an open source alternative selfhosted front-end to YouTube.

## Features

- No ads
- No tracking
- No JavaScript required

## SponsorBlock

Invidious does not have built in Sponsorblock how it has piped. But you can use the Browser SponsorBlock Addon on the Invidious page by Open the settings navigate to `Miscellaneous`. Her you have to enable `Support 3rd Party YouTube-Sites` and add your domain to the Instance list via `Add 3rd-Party Client Instance`. Apply the changes via `Save`.
