# Navidrome

Navidrome is an open source web-based music collection server and streamer.

## Clients

### Linux

- [feishin](https://github.com/jeffvli/feishin)

### Androide

- [Symfonium](https://symfonium.app): Ontime Payment required!, Play and cast music from your Android device, Plex, Emby, Jellyfin, Subsonic, OpenSubsonic, Kodi, Samba (SMB v2/v3), WebDAV servers or supported Cloud providers (Google Drive, OneDrive, DropBox, Box, pCloud)
